**VoiceShield** is an AI-powered real-time detection system engineered to detect and prevent voice-cloning and AI-generated voice impersonation attacks in voice communication streams.

---

## 🚀 Core Detection Pipeline

```
Audio Input (WAV File / WebSocket PCM Stream)
   │
   ▼
[ Audio Validation & Preprocessing ] ──> Format: 16 kHz, 16-bit PCM, Mono
   │
   ├───────────────────────────────────────────────────────┐
   ▼                                                       ▼
[ Silero Voice Activity Detector ]                 [ Bispectral Higher-Order Analysis ]
   │ (Extracts speech timestamps, duration & slices)  │ (Detects vocoder phase coupling & artifacts)
   │                                                       │
   ├───────────────────────────────┐                       │
   ▼                               ▼                       │
[ AASIST Graph Anti-Spoof ]     [ ECAPA-TDNN Verifier ]     │
   │ (Spectro-Temporal GAT         │ (Speaker similarity   │
   │  LA deepfake detection)       │  against reference)   │
   └───────────────┬───────────────┴───────────────────────┘
                   │
                   ▼
         [ Risk Fusion Engine ]
         (Platt calibration & multi-feature weighted fusion)
                   │
                   ▼
         [ Calibrated Risk Assessment ]
         (Risk Score, Risk Level, Actionable Decision, Provenance)
                   │
                   ▼
     [ REST JSON / WebSocket Stream Response ]
```

## 🔬 Scientific Provenance Tracking

To maintain scientific rigor and avoid deceptive AI claims, every metric emitted by VoiceShield includes an explicit **provenance tag**:

| Provenance Level | Description |
|---|---|
| `REAL_MODEL` | Value generated by a loaded, verified deep learning neural network (e.g. Silero VAD, AASIST, ECAPA-TDNN). |
| `SIGNAL_ANALYSIS` | Value computed from deterministic mathematical & DSP higher-order spectral algorithms (e.g. Bispectral analysis, Bicoherence, RMS energy). |
| `PLACEHOLDER` | Model architecture loaded without pretrained weights checkpoint; structural interface preserved without fabricating artificial inference. |
| `MOCK` | Explicit synthetic simulation for unit testing. |

## 🛠️ Technology Stack

- **Backend Framework**: Python 3.10+ (Verified 3.11.9) / FastAPI / Uvicorn
- **AI & Deep Learning**: PyTorch / Torchaudio
- **Voice Activity Detection**: Silero VAD (JIT Neural Network + DSP fallback)
- **Deepfake Anti-Spoofing**: AASIST (`clovaai/aasist`, Spectro-Temporal Graph Attention Network)
- **Speaker Verification**: ECAPA-TDNN (192-d speaker embeddings, VoxCeleb pretrained)
- **Signal Analysis**: Bispectral Analysis & Higher-Order Statistics (NumPy / SciPy)
- **Risk Assessment**: Multi-modal fusion with Platt scaling probability calibration
- **Real-Time Streaming**: Full-duplex WebSockets

## ⚡ Quickstart & Setup

### 1. Installation

```bash
# Clone repository
git clone https://github.com/your-org/voiceshield.git
cd voiceshield

# Install dependencies
pip install -r requirements.txt
```

### 2. Configure Environment

```bash
cp .env.example .env
```

### 3. Download / Verify Model Checkpoints

```bash
# Download AASIST, ECAPA-TDNN, and Silero VAD checkpoints
python scripts/download_models.py --model all
```

### 4. Run Diagnostics & Verification

```bash
python scripts/diagnose_aasist_outputs.py
```

### 5. Run Full Pytest Suite

```bash
pytest backend/tests -v
```

### 6. Launch FastAPI Backend

```bash
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

Interactive Swagger API documentation is available at: `http://localhost:8000/docs`
Prototype Demonstration Dashboard: `http://localhost:8000/demo`

## 📡 API Reference & Examples

### `POST /api/analyze`
Submits a WAV audio file (and optional reference speaker audio) for full multi-modal anti-spoofing and speaker verification analysis.

**cURL Example:**
```bash
curl -X POST "http://localhost:8000/api/analyze" \
  -F "file=@data/demo/speaker_a_sample2.wav" \
  -F "reference_file=@data/demo/speaker_a_sample1.wav" \
  -F "auto_convert=true"
```

**Response Format:**
